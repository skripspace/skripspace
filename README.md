# SKRIPSPACE — Your Academic Workspace

Aplikasi web layanan skripsi Program Studi S1 Ilmu Hukum, Fakultas Hukum UNISSULA: pengajuan judul, izin riset, dan catatan bimbingan skripsi.

Buka: https://skripspace.github.io/skripspace/

Berkas di repositori ini adalah tampilan aplikasi (halaman statis yang bisa dipasang di HP). Data tersimpan di Google Sheets milik prodi dan diakses lewat Google Apps Script.
